# H2 robot model

`get_robot_cfg("h2")` (alias `unitree_h2`) provides the 31-joint H2 model,
38-element floating-base qpos, limits, nominal posture, and simulation actuator
parameters. XML and meshes resolve through mjhub from the shared pinned asset
`hf://elijahgalahad/h2_model@beb532e8717b99816b93baace0c649a599538715/h2.xml`.
No sibling training checkout or bundled model copy is needed. Warm the Hugging
Face cache once online before setting `HF_HUB_OFFLINE=1` for offline use.

This registration supports model loading and robot-matched simulation. It does
not add an H2 hardware DDS adapter or an H2 Pico retarget configuration. Those
must be validated, together with the exported policy observation/action order,
before hardware deployment. Do not use the G1 hardware adapter for H2.

The existing RP1 implementation remains on the private RP1 branch/repository.
