# H2 robot model

`get_robot_cfg("h2")` (alias `unitree_h2`) provides the 31-joint H2 model,
38-element floating-base qpos, limits, nominal posture, and simulation actuator
parameters. XML and meshes resolve through mjhub from the shared pinned asset
`hf://elijahgalahad/h2_model@beb532e8717b99816b93baace0c649a599538715/h2.xml`.
No sibling training checkout or bundled model copy is needed. Warm the Hugging
Face cache once online before setting `HF_HUB_OFFLINE=1` for offline use.

Pico retargeting supports `--robot h2` using the packaged XRobot mapping and the
same pinned H2 model. From the repository root:

```bash
uv run --project venv/pico sim2real/teleop/pico_retarget_pub.py --robot h2 --actual-human-height 1.8 --publish-hz 50
```

Set actual human height to the operator's measured height. The user-supplied
mapping uses a 1.66m calibration height with separate upper/lower-body scales,
roll-link hip/shoulder targets, and separate ankle-position/foot-orientation
constraints. Input must include Left_Ankle and Right_Ankle. Synthetic upright retargeting
is tested; live Pico calibration remains unverified. This publishes reference
motion only and does not add an H2 hardware DDS adapter. Do not use the G1
hardware adapter for H2.

The existing RP1 implementation remains on the private RP1 branch/repository.
